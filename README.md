# 智库 Demo

**[点击打开在线 Demo](https://leo131496.github.io/HTEP/)**

可直接打开的移动端智库交互原型，按照 iPhone 14 Pro 的 **393 × 852** 尺寸设计。HTML 内置样式、脚本及示例文件，无需安装依赖或构建。

## 使用

下载仓库后，使用 Chrome、Edge 或 Safari 打开 [`index.html`](index.html)。也可通过任意静态网站服务托管。

在线体验请访问 **https://leo131496.github.io/HTEP/**。本站通过 GitHub Pages 从 `main` 分支根目录发布，更新该分支后会自动部署。

## 功能

- 同一个搜索栏切换知识检索与评论互动。
- 我的评论、我的分享、我的收藏、我的下载，分别进入独立记录页。
- 进入详情直接阅读 PDF、Word、Excel、图片或播放视频。
- 评论支持图片、回复和点赞，附件名称可点击定位正文。
- 下载按钮仅显示图标，直接触发原文件下载。
- 微信风格底部分享面板：发送给朋友、分享到朋友圈、取消。
- 内置示例评论、分享、收藏、下载记录；新增操作可在当前浏览器保存。

## 演示说明

示例文件、评论与历史记录均为模拟内容，不替代正式技术文档。本项目没有连接生产后台，个人操作记录保存在当前浏览器；清除浏览器数据会清除对应记录。

支持系统分享的手机浏览器会提交文件、知识卡片或公开链接供用户选择分享应用；否则会尝试通过 `weixin://` 打开微信。网页无法保证直接进入指定好友或朋友圈发布页，也不能通过该协议自动带入内容。微信内置浏览器使用右上角菜单分享。真实微信渠道直达需要相应原生端或微信开放能力接入，本 Demo 未做真实微信客户端联调。

本地文件及 localhost 链接只适用于当前设备；公开托管后，内置知识的链接可跨设备访问。下载记录表示已向浏览器发起下载，保存目录及系统提示由浏览器决定。
