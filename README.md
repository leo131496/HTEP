# 素材库 Demo

**[打开统一演示页面](https://leo131496.github.io/HTEP/)**

打开同一个地址，通过顶部「手机端 / 管理后台」两个 tab 切换。切换时保留页面位置、表单输入和手机端登录状态。默认显示手机端，后台直接进入管理界面。

[后台功能设计](admin/README.md)

## 两端功能与进入方式

| 入口 | 进入方式 | 功能 |
| --- | --- | --- |
| 手机端 | 员工手机号 + 验证码 | 素材浏览、检索、下载、分享、收藏、评论和我的互动 |
| 管理后台 | 无需登录，直接进入 | 员工、内容、目录、权限、审核、数据看板和排名 |

手机端演示：手机号 `13900000004`，点击获取验证码后输入 `123456`。短信为演示，不发送真实短信。后台员工管理维护手机端账号，不分配后台登录角色。

## 使用

仓库根目录的 `index.html` 是统一演示页；手机端在 `mobile/index.html`，后台在 `admin/index.html`。本地请使用静态 HTTP 服务打开根目录，例如 `python3 -m http.server 4188 --bind 127.0.0.1`。

在线体验请访问 **https://leo131496.github.io/HTEP/**。本站通过 GitHub Pages 从 `main` 分支根目录发布，更新该分支后会自动部署。统一页支持 tab 键盘切换、浏览器前进/后退和刷新恢复当前端；原有素材详情链接仍可通过首页打开。

## 文件夹浏览

素材列表采用网盘式文件夹与文件行，最多三级文件夹（不含「全部文件」根目录）。当前目录展示直属子文件夹和素材文件；文件夹上的素材数包含其所有下级内容。路径导航和返回上一级可切换目录，点击文件进入对应素材详情，详情可返回原目录。目录链接支持刷新和浏览器前进、后退。

演示分类包括「清洁保养」「安装施工」「产品知识」；三级示例为「清洁保养 / 地毯养护 / 日常清洁」。原有历史文件未指定目录时保留在根目录。

搜索与文件类型筛选覆盖当前目录及所有子文件夹，结果显示所属路径；清除筛选后恢复文件夹浏览。目录为 Demo 内置分类，尚未接入后台目录管理。

## 功能

- 同一个搜索栏切换素材检索与评论互动。
- 我的评论、我的分享、我的收藏、我的下载，分别进入独立记录页。
- 进入详情直接阅读 PDF、Word、Excel、图片或播放视频。
- 评论支持图片、回复和点赞，附件名称可点击定位正文。
- 下载按钮仅显示图标，直接触发原文件下载。
- 微信风格底部分享面板：发送给朋友、分享到朋友圈、取消。
- 内置示例评论、分享、收藏、下载记录；新增操作可在当前浏览器保存。

## 演示说明

示例文件、评论与历史记录均为模拟内容，不替代正式技术文档。本项目没有连接生产后台，个人操作记录保存在当前浏览器；清除浏览器数据会清除对应记录。

支持系统分享的手机浏览器会提交文件、素材卡片或公开链接供用户选择分享应用；否则会尝试通过 `weixin://` 打开微信。网页无法保证直接进入指定好友或朋友圈发布页，也不能通过该协议自动带入内容。微信内置浏览器使用右上角菜单分享。真实微信渠道直达需要相应原生端或微信开放能力接入，本 Demo 未做真实微信客户端联调。

本地文件及 localhost 链接只适用于当前设备；公开托管后，内置素材的链接可跨设备访问。下载记录表示已向浏览器发起下载，保存目录及系统提示由浏览器决定。
